===========================================================
           INSTALLING FLIPKIT ON MAC
===========================================================

  IMPORTANT: Do NOT double-click to open!

  Because FlipKit is not from the Mac App Store,
  macOS will block it by default.

  To install:

  1. Drag FlipKit to your Applications folder
  2. RIGHT-CLICK on FlipKit.app
  3. Select "Open" from the menu
  4. Click "Open" in the dialog that appears

  You only need to do this once. After that,
  FlipKit will open normally.

===========================================================
              TROUBLESHOOTING
===========================================================

  "FlipKit is damaged and can't be opened"

  Run this command in Terminal:
    xattr -cr /Applications/FlipKit.app

  Then try the right-click method again.

-----------------------------------------------------------

  Still can't open?

  1. Go to System Settings > Privacy & Security
  2. Scroll down to find "FlipKit was blocked"
  3. Click "Open Anyway"
  4. Enter your password
